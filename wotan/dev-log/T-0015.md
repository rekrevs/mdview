# T-0015: Make file watching survive atomic saves and release all descriptors

**Status**: DONE | **Size**: M
**Phase**: DONE

## Context

User authorized a complete improved mdview version on 2026-09-27, including refactoring/rewrite and Wotan execution. Baseline: review/2026-09-27/REVIEW.md.

## Acceptance and verification plan

Resolve R7–R8. Watch the containing directory, debounce, survive repeated replacement/delete/recreate, close descriptors exactly once. Swift Testing with positive change controls and lifecycle checks (the installed Command Line Tools provide Testing.framework but no XCTest).

## Approach

Combine a parent-directory kqueue source (pathname replacement and recreation) with a file source (in-place writes). Compare inode/device and timestamps/size to ignore unrelated directory changes; reattach the file source when identity changes. Debounce callbacks for 100 ms and deliver on the main queue. Serialize stop with callbacks, cancel sources idempotently, and close each descriptor in a cancellation closure that owns its numeric descriptor rather than a weak reference to the watcher.

```sh
env CLANG_MODULE_CACHE_PATH=/tmp/mdview-watcher-tests/clang-cache \
  SWIFTPM_MODULECACHE_OVERRIDE=/tmp/mdview-watcher-tests/module-cache \
  SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk \
  swift test --disable-sandbox --package-path /tmp/mdview-watcher-tests \
  --build-system native --sdk /Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk \
  -Xswiftc -F/Library/Developer/CommandLineTools/Library/Developer/Frameworks \
  -Xswiftc -plugin-path \
  -Xswiftc /Library/Developer/CommandLineTools/usr/lib/swift/host/plugins/testing \
  -Xlinker -rpath \
  -Xlinker /Library/Developer/CommandLineTools/Library/Developer/Frameworks
```

Toolchain notes: XCTest is absent from this CLT installation, so tests use Swift Testing. Explicit framework, macro-plugin, and runtime paths are necessary with the native SwiftPM build system.

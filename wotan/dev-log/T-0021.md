## Context

Real READMEs use `<details>`, `<summary>`, `<kbd>`, `<sub>`, `<sup>`, `<br>`, `<img width>`, `<p align>`, `<picture>`. mdview shows all raw HTML as text. Must keep the guarantee that only bundled scripts execute.

- [ ] No script, event handler, javascript:/data: script URL, iframe, form, style injection or remote fetch beyond existing image policy
- [ ] Links/images inside allowed HTML go through the same link classification and relative resolution
- [ ] Adversarial renderer tests plus GUI evidence; README and CLAUDE.md constraint wording updated

## Approach

Planned 2026-11-03 (Plan agent, Opus 5.5 xhigh).

- Decision: in-house token-level canonicalizer (`Sources/Resources/Web/html-policy.js`, `installHTMLPolicy(md)`), not DOMPurify. Author HTML is re-emitted as escaped text plus tags built from fixed allowlisted names/attributes with validated, escaped values, so author bytes never reach WebKit as markup (no mXSS/parser differential). DOMPurify rejected: strips instead of showing text, needs whole-output DOM pass that would also hit KaTeX/hljs/Mermaid, jsdom≠WebKit.
- Disallowed tags/doctype/PI/CDATA stay visible text; raw-text elements (script, style, textarea, iframe, svg, math, template, …) shown verbatim to their close tag; disallowed attributes dropped; unsafe `a` href → text, unsafe img src → existing fallback; comments hidden (documented exception).
- Allowlist after html-pipeline: headings, p, div, blockquote, pre, lists, dl, tables, details/summary, figure, picture/source, hr, br, wbr, img, a, inline formatting (b,i,strong,em,del,ins,s,strike,sub,sup,kbd,code,tt,samp,var,q,cite,dfn,abbr,mark,small,span,time,ruby,rt,rp,bdo). Attributes: title, lang, dir, aria-label/hidden, id/name → `user-content-` prefix; a href; img src/alt/width/height/align/loading; source srcset/media/type; align/valign/width/colspan/rowspan/scope/border/start/type/value/open/datetime with strict value patterns.
- URLs: decode refs, strip tab/CR/LF/controls, then: a → fragment, relative, http(s), mailto (via md.validateLink/normalizeLink); img/srcset → relative, http(s), raster data images. No file:, mdview-image:, //host, blob:, svg data.
- Pipeline: `html:true`; core rule `author_html` pushed last converts html_block/html_inline → `author_html`; inline formatting closed per token, containers balanced across blocks via env stack; html_* renderers always escape (fail closed). Task checkbox becomes its own token type. `render()` parses into `<template>` and resolves images before insertion. scroll/find open enclosing `<details>`; copy handles picture/source/closed details.
- Defence in depth already present: CSP script-src 'self', default-src 'none', navigation policy.
- Tests: allowed constructs (exact canonical strings), disallowed visible, attribute stripping, URL corpus, Markdown parity, balancing, mXSS corpus with shared `assertInert`, survival of math/hljs/checkbox/front matter, copy/find/anchors, DOM clobbering; Swift LinkDestination hostile hrefs; GUI: summary click, kbd/align styles, picture appearance, link routing, adversarial corpus, CSP proof.

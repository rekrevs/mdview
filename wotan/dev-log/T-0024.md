## Approach

Planned 2026-11-03 (Plan agent, Opus 5.5 xhigh).

- View-based `QLPreviewingController` (NSViewController + WKWebView, `QLIsDataBasedPreview=false`); data-based HTML previews don't run JS. Thumbnails out of scope (follow-up).
- Appex `Contents/PlugIns/mdviewQuickLook.appex` with its own copy of the resource bundle; links inert except anchors; remote images allowed (network.client); local relative images via read-only temporary exception; 4 MiB truncation with note; 10 s render timeout; dark mode via CSS.
- Package.swift: new `ReaderCore` library target (LocalImageHandler, new `RendererPage` shared config/index lookup/render options), `mdviewQuickLook` executable target linked with `-e _NSExtensionMain` (fallback: dlsym in main.swift; plan C: swiftc in bundle.sh).
- Appex Info.plist generated in bundle.sh (`com.mdview.app.quicklook`, XPC!, NSExtension quicklook.preview, principal `MDViewPreviewController`, `QLSupportedContentTypes` net.daringfireball.markdown + whatever mdls reports). Entitlements file `Packaging/QuickLook.entitlements` (app-sandbox, network.client, read-only exception). Sign inside-out without `--deep`.
- validate-bundle checks both resource copies identical, plist keys, sandbox entitlement, principal class symbol. install.sh: lsregister, pluginkit -a/-r for backups, qlmanage -r.
- check-reader.py compiles ReaderCore first.
- Verification: `scripts/check-quicklook.sh` + `make quicklook-test` (pluginkit registration, `qlmanage -p` with os.Logger stats line: katex count, highlighted code, image loaded, inert HTML, bundle path), relocated bundle, manual Finder Space checks.
- Fallback B: data-based preview with JavaScriptCore pre-render (loses Mermaid).

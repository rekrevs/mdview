## Decisions

- A single DOM document provides continuous selection and browser line layout. markdown-it handles recursive block/inline structure; first-party math token rules consume original source before Markdown escape/emphasis processing.
- Supported math: `$…$`, GitHub `$`backtick`…`backtick`$`, `$$…$$` including separate delimiter lines, and `math` fences. Escaped dollar signs, code, and prices such as `$5 and $10` stay literal. Numeric formulas such as `$2$` remain valid. KaTeX errors display original source with an error tooltip rather than dropping content.
- Formula clipboard output is original delimited TeX exactly once, replacing visual/MathML duplicate branches. Partial formula selection expands to the whole formula. Native Select All may anchor at BODY; the document-level clipboard handler clamps this to MAIN. Code copy buttons preserve exact parser code text including indentation, internal blank lines, and final newline.
- Search joins visible prose/code text across inline styles and excludes formulas and controls. DOM ranges implement matches without rewriting text nodes; CSS Highlight is used when supported, with selected-range fallback. Search indices are one-based, zero when empty.
- Raw HTML is displayed literally (`html: false`); document scripts never run. KaTeX runs with `trust: false`, expansion/size limits, and CSP blocks scripts/network connections beyond bundled scripts and permitted image schemes. Remote HTTP(S) images may need a connection; renderer libraries/fonts do not.
- Local image URLs use `mdview-image://local` plus the resolved file URL's percent-encoded pathname. Native routing decodes once and applies filesystem policy. Missing images show their alt text and an explicit unavailable label.
- Renderer API: `window.mdview.render(markdown,{baseURL})` → `{headings,changed}`, `setZoom(scale)`, `scrollToHeading(id)` → boolean, `find(query,direction=1,reset=false)` → `{count,index}`. Bridge messages: ready, rendered, headings, link, copy. Identical-source render preserves DOM and selection. Empty heading fragment scrolls to document top.
- Mermaid is deliberately not claimed/implemented in this task; diagram fences remain readable code. No competitor application code was copied.
